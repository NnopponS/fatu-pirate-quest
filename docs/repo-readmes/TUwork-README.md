## 📖 เกี่ยวกับโปรเจค

**TUwork** คือแพลตฟอร์มตลาดงานสำหรับนักศึกษา ออกแบบมาเพื่อเชื่อมต่อนักศึกษาที่ต้องการงานพาร์ทไทม์และบริการต่างๆ กับผู้ที่ต้องการจ้าง ภายในชุมชนมหาวิทยาลัย

## ✨ Features หลัก

- 🔍 **ค้นหางาน** — กรองตามประเภทงาน เวลา ค่าจ้าง
- 📝 **โพสต์งาน** — นักศึกษาและนายจ้างลงประกาศรับสมัครได้
- 👤 **โปรไฟล์** — แสดงทักษะ ประสบการณ์ และ portfolio
- 💬 **ระบบแชท** — สื่อสารระหว่างผู้จ้างและผู้สมัครงาน
- ⭐ **ระบบรีวิว** — ให้คะแนนและรีวิวหลังจบงาน
- 🔔 **การแจ้งเตือน** — แจ้งเตือนเมื่อมีงานใหม่ที่ตรงความสนใจ

## 🚀 Getting Started

```bash
# Clone และ install
git clone <repo-url>
cd TUwork
npm install

# ตั้งค่า environment
cp .env.example .env
# แก้ไข .env ใส่ค่าจริง

# รัน dev server
npm run dev
```
