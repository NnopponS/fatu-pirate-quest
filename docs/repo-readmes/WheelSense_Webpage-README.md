## 📖 เกี่ยวกับโปรเจค

**WheelSense Webpage** คือเว็บไซต์นำเสนอโปรเจค WheelSense ระบบ IoT เพื่อช่วยเหลือผู้ใช้วีลแชร์ในการตรวจจับสิ่งกีดขวางและแจ้งเตือนแบบ real-time

## 🌐 หน้าเว็บ

| หน้า | คำอธิบาย |
|------|---------|
| `index.html` | หน้าแรก — Overview โปรเจค |
| `projects.html` | รายละเอียดโปรเจคและฟีเจอร์ |
| `story.html` | แรงบันดาลใจและที่มาของโปรเจค |
| `member.html` | ทีมผู้พัฒนา |
| `awards.html` | รางวัลที่ได้รับ |
| `contact.html` | ช่องทางติดต่อ |
| `admin.html` | หน้าจัดการสำหรับ Admin |

## ✨ Features

- 🎨 **Responsive Design** — รองรับทุกขนาดหน้าจอ
- 📊 **Live Dashboard** — แสดงข้อมูล sensor แบบ real-time
- 🗺️ **Maps Integration** — แสดงตำแหน่งและเส้นทาง
- 📱 **Mobile-first** — ออกแบบให้ใช้งานบนมือถือสะดวก

## 🛠️ Tech Stack

- **Frontend:** HTML5 + TypeScript + Vite
- **Styling:** CSS3 (ระบุ CSS framework ถ้ามี)
- **Backend API:** (ระบุ API endpoint)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# รัน dev server
npm run dev

# Build for production
npm run build
```
