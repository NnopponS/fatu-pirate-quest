# 📚 README Templates สำหรับ GitHub Repositories ของ NnopponS

โฟลเดอร์นี้รวม README.md ที่พร้อมใช้งานสำหรับทุก repository ของ NnopponS

## วิธีนำ README ไปใช้

สำหรับแต่ละ repo ที่ต้องการ:
1. เปิดไฟล์ README ที่ต้องการจากรายการด้านล่าง
2. Copy เนื้อหาทั้งหมด
3. ไปที่ GitHub repo นั้น → สร้างหรือแก้ไขไฟล์ `README.md`
4. วาง content และ commit

## หมายเหตุ

แต่ละ README template ใช้รูปแบบที่:
- มี badges แสดง tech stack
- มีการอธิบายโปรเจคอย่างชัดเจน
- มีคำแนะนำการติดตั้งและใช้งาน
- ใช้ emoji เพื่อความน่าอ่าน
- รองรับทั้ง English และ Thai
